# 面试弱点防御

本文用于准备“你们的方法哪里不够好”“这个结论有没有夸大”的追问。每个点都按三段式组织：

1. 承认问题
2. 解释为什么当前做法仍然合理
3. 给出具体可行的改进方向

## 1. 数据局限：只有 34 个赛季，而且没有真实投票数据

### 承认

这是整个项目最根本的限制。我们没有真实观众投票标签，只能看到评委分数和淘汰结果，因此 Task 1 做的是隐藏变量推断，而不是直接监督学习。另一方面，34 个赛季在制度分析里不算特别小，但也谈不上特别大，尤其对细分规则和边界案例的统计检验会有限制。

### 合理化

这个限制恰好也是题目的核心挑战。我们没有回避它，而是把问题重写成 `constrained Bayesian inverse problem`，用 simplex constraint、淘汰硬约束和时间平滑把可行空间压缩到足够小。换句话说，我们不是假装自己有真实投票数据，而是在承认数据缺口的前提下，给出最合理的结构化推断。

### 未来改进

- 引入社交媒体热度、搜索指数或节目外互动数据，作为 fan-share 的外部先验信息。
- 若能获得局部真实投票样本，可用作后验校准或半监督验证。
- 对不同赛制阶段分层建模，减少“所有赛季共用一套结构”的压力。

### 面试自然说法

我们最大的限制不是样本太少，而是最关键的投票标签看不到。所以我们没有把它包装成普通预测题，而是老老实实做成了受约束的逆问题。

## 2. 方法局限：indicator likelihood 有信息损失

### 承认

indicator likelihood 只利用了“这组参数能不能解释真实淘汰”，没有利用“距离淘汰边界还有多远”的连续信息，因此信息利用是粗粒度的。它会让后验边界更尖锐，也会让采样难度变高。

### 合理化

在这个题目里，离散淘汰事件本身就是最可信、最稳定的观测。相比之下，如果强行设计连续似然，我们还需要额外假设“离 bottom 多远时淘汰概率会怎样变化”，而这个映射在无真实投票标签时并没有可靠外部依据。所以当前做法是在“信息利用”和“假设可信度”之间做了偏保守但更稳的选择。

### 未来改进

- 尝试 soft-indicator likelihood，例如用 logistic/probit 把“距离淘汰边界”连续化。
- 对硬约束模型和连续似然模型做严格 ablation study，比较精度与稳定性。
- 若能引入外部人气代理变量，可对连续映射参数做标定。

### 面试自然说法

是的，硬约束似然确实牺牲了一部分细节信息，但它换来的是规则表达更直接、假设更少，在当前数据条件下我认为这是更稳的主模型。

## 3. 方法局限：MCMC 计算成本高

### 承认

MCMC 明显不是最低成本方案。Task 1 默认 warm-up 3000、采样 10000，还要跨赛季运行，计算代价高于普通优化方法或近似推断。

### 合理化

我们选择 MCMC 的原因不是“它高级”，而是因为这里需要 posterior uncertainty，而不是单点解。尤其在多解、边界周、Judges' Save 阶段，仅给一个最优点会丢掉大量信息。为了控制工程成本，我们已经通过缓存、约束前置和自动 ESS 检查把重复运行代价压下来了，草稿记录的首次运行约 32 分钟，命中缓存后约 20 秒。

### 未来改进

- 在更大规模数据下，用变分推断或 SMC 做近似替代。
- 按赛季做并行化，把独立计算任务拆到多进程或多节点。
- 针对约束结构设计更高效的 proposal，而不是单纯随机游走。

### 面试自然说法

MCMC 确实慢，但它慢得有价值，因为我们换回来的是完整后验和不确定性表达，而不是一个无法解释置信度的点估计。

## 4. 结果局限：93.49% 很高，但不是“完全解释”

### 承认

93.49% 的重构准确率说明模型抓住了主机制，但它不是 100%。剩下约 6.5% 的周次仍然没有被完全解释，尤其是在 S28+ 的 Judges' Save 阶段，严格准确率会明显下降。

### 合理化

这并不意味着模型失败，而是说明节目机制里确实存在额外的人为决策、特殊周规则和未观测噪声。相反，如果我们在看不到真实投票的前提下还宣称“完全恢复真相”，反而是不严谨的。我们同时报告了 `bottom-2 recall`、constraint satisfaction rate 和 sensitivity analysis，就是为了避免只拿一个高分数讲故事。

### 未来改进

- 单独为 S28+ 建立更细的 Judges' Save 决策模型。
- 把特殊赛制周、团队周、复活赛周显式建模，而不是统一处理。
- 细化 anomaly case analysis，单独解释尚未重构成功的周次。

### 面试自然说法

93.49% 的意义是“主要机制被识别了”，不是“节目里所有细节都被我们完全还原了”。

## 5. 结果局限：\(\Delta\tau=0.022\) 的实际意义需要克制表述

### 承认

PTFS 相比 Percentage-based 的 Kendall's \(\tau\) 提升是 0.022，这不是一个肉眼看上去特别大的数字。如果夸张地说成“革命性改进”，是不合适的。

### 合理化

但它也不是可以忽略的噪声。首先，这个提升是在 34 个赛季的制度比较中得到的；其次，显著性检验给出 \(p=0.031\)，说明它不是随机抖动；再次，PTFS 不是只提升了 \(\tau\)，它还把 Close Call Rate 提到 79.1%，Consistent Seasons 提到 97.1%，说明它是在多维指标上同步改善。

### 未来改进

- 做更细的 season-level breakdown，分析改进主要发生在哪些赛季和哪些边界周。
- 引入更多业务化指标，例如观众留存、爆冷可接受度等，丰富“实际意义”解释。
- 做更系统的权重敏感性分析，识别 PTFS 的稳健区间而不是只报最优点。

### 面试自然说法

我会把它表述成“小幅但显著的制度改进”，而不是夸成压倒性优势。

## 6. 解释局限：Task 3 是相关结构，不是严格因果识别

### 承认

Task 3 的混合效应模型回答的是“哪些因素和评分/投票存在系统关联”，不是严格意义上的因果推断。比如 Athlete Paradox 说明方向反转，但不能直接推断成“评委歧视运动员”之类的强因果结论。

### 合理化

我们在论文叙事里把它定位为 `mechanism interpretation` 而不是因果识别，这一点是清楚的。混合效应模型的价值在于拆分技术通道和人气通道，识别统计结构差异，而不是替代实验设计。

### 未来改进

- 如果能拿到更细粒度特征，可结合 causal graph 做更明确的识别假设。
- 引入自然实验或规则变更前后的断点分析，增强因果解释力度。
- 对 Task 3 使用贝叶斯层次模型，让不确定性传播更一致。

### 面试自然说法

Task 3 的关键词是“解释机制差异”，不是“证明严格因果”。这个边界我会讲得很清楚。

## 7. 泛化局限：从 DWTS 到其他场景不能直接照搬

### 承认

我们的数据和规则都来自 `Dancing with the Stars`，所以结论天然带有场景依赖。不能直接把数值结论，比如 90.5% 或 21.8%，外推到所有选秀节目或所有评分系统。

### 合理化

不过，可迁移的是方法框架，而不是数值本身。只要一个场景同时满足“隐藏公众偏好 + 公开结果 + 明确规则”，我们的主线方法就依然成立：先做隐变量推断，再做双轨解释，最后做规则设计。

### 未来改进

- 在其他节目或赛事上做外部验证，例如《The Voice》或电竞评审赛制。
- 把规则映射函数做成更通用的可配置接口，降低迁移成本。
- 对不同类型场景重新学习先验结构和评价权重，而不是直接复用 DWTS 参数。

### 面试自然说法

这个项目可泛化的是框架，不是把所有数字原封不动搬去别的节目。

## 8. 主动防守总表

| 弱点 | 承认 | 防守核心 | 改进方向 |
| --- | --- | --- | --- |
| 无真实投票数据 | 标签缺失 | 题目本身就是逆问题 | 引入外部人气数据 |
| Indicator likelihood 粗糙 | 信息损失 | 假设更少、更稳 | soft likelihood 对照实验 |
| MCMC 慢 | 计算成本高 | 换来 posterior 和 uncertainty | VI / 并行 / 更强 proposal |
| 93.49% 非满分 | 仍有边界案例 | 主机制已被识别 | 专门建模特殊规则 |
| \(\Delta\tau=0.022\) 不大 | 提升温和 | 小幅但显著，且多维改善 | 做更细 season 分解 |
| Task 3 非因果 | 只是相关结构 | 我们从未把它说成因果识别 | 加自然实验或因果设计 |
| 场景依赖 | 来自单一节目 | 可迁移的是框架 | 做外部验证 |

## 最后一句

这份防御的核心策略不是“把弱点说没”，而是把弱点变成合理边界：我们承认它、解释它、再说明为什么当前方案在比赛约束下仍然是高质量选择。
